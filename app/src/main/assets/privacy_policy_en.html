HamKit Privacy Policy

Version 2.0 · Effective 2026-11-07

HamKit is local-first. Data leaves the device only for features you enable (AI, APRS, maps, MCP).

1. Data we process

  • Location (zones, grid, satellites, map), only after consent.
  • Microphone/audio for local SSTV/FT8/APRS decoding.
  • Attachments you pick (images/text/audio) for the current AI request.
  • Chats and tool results, stored locally.
  • API keys, encrypted with Android Keystore.
  • Device/network info for diagnostics (not uploaded).
  • MCP requests from LAN clients with a valid token (not logged).

2. Purposes

Provide features, diagnose crashes, comply with law.

3. Third parties

  • Your chosen AI provider (OpenAI/Anthropic/Gemini/DeepSeek/self-hosted).
  • AMap (map/geocoding).
  • AMSAT/SatNOGS/CelesTrak (satellite data).
  • APRS-IS (only when APRS upload is enabled).

4. Storage

Local app-private storage; API keys Keystore-encrypted; cleartext HTTP and self-signed TLS are opt-in and limited to private hosts.

5. Permissions

Location, microphone, notifications, foreground service, optional install-package.

6. Your rights

Clear chats/logs, reset keys, disable MCP, or withdraw consent in Settings.

7. Children

Not directed to children under 13.

8. Changes

Material changes require re-consent.
