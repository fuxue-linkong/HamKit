HamKit 隐私政策

版本 2.0 · 生效日期：2026 年 11 月 7 日

HamKit 以本地处理为优先。除你主动开启的功能（AI 对话、APRS 上报、地图、MCP）外，应用不会把你的数据上传到开发者服务器。

一、我们收集哪些信息

  • 位置：用于 CQ/ITU 分区、Maidenhead 网格、卫星过境与地图。精确位置仅在同意后请求；可拒绝，拒绝后相关功能不可用。
  • 麦克风/音频：仅在你使用 SSTV、FT8、APRS 接收时采集，用于本地解码；音频默认不保存。
  • 附件：你选择的图片/文本/音频；图片压缩后仅随当前 AI 请求发送。
  • AI 对话与工具结果：默认保存在本机；开启“保存对话历史”后写入本地数据库。
  • API Key：使用 Android Keystore AES-256-GCM 加密保存，不写入日志。
  • 设备与网络信息：网络类型、系统版本，用于诊断与兼容；不上传。
  • MCP 请求：开启局域网 MCP 后，局域网客户端携带 Token 的请求会由本机处理；不记录请求内容。

二、使用目的

提供定位/分区、卫星预测、解码、日志、SSTV、AI 对话与局域网 MCP 功能；排查崩溃与兼容问题；履行法律义务。

三、第三方服务

  • AI 服务商：你配置的 OpenAI/Anthropic/Gemini/DeepSeek 或自建服务；对话与附件会发送给该服务商，适用其隐私政策。
  • 高德地图：地图与逆地理编码（需同意后初始化）。
  • AMSAT / SatNOGS / CelesTrak：卫星状态与 TLE。
  • APRS-IS：仅在开启 APRS 上报时连接。

四、存储与保护

数据默认存储在本机应用私有目录；API Key 使用 Android Keystore 加密；HTTP 明文与自签证书默认关闭，仅对私有地址开放。卸载应用会删除本地数据。

五、权限清单

  • 定位（精确/粗略）：分区、网格、卫星、地图。
  • 麦克风：SSTV/FT8/APRS 解码。
  • 通知：过境提醒。
  • 前台服务：后台定位/解码与提醒。
  • 安装包请求：应用内更新（可选）。

六、你的权利

你可以在设置中清除对话历史、删除 QSO 日志、重置 API Key、关闭 MCP，或撤回隐私同意（将退出应用）。如需导出数据，请使用应用内导出功能。

七、儿童

HamKit 不面向 13 岁以下儿童；若你未满法定年龄，请在监护人指导下使用。

八、变更

政策实质变更时会再次要求阅读并同意；版本号与应用内展示保持一致。

九、联系

隐私问题请通过应用内“关于”页面的仓库地址反馈。
