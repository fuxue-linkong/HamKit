HamKit User Agreement

Version 2.0 · Effective 2026-11-07

By checking the box you accept this agreement and the Privacy Policy.

1. Service

HamKit is an amateur-radio helper (satellite passes, FT8/APRS, QSO log, SSTV, zones, Morse, optional AI). It is not an official QSO platform and does not control transmitters.

2. Compliance

  • You must hold a valid amateur licence where required.
  • Follow local band plans, power limits and callsign rules.
  • APRS position disclosure is opt-in and off by default.

3. AI features

  • Answers come from third-party models and may be wrong.
  • Write actions ask for confirmation before executing.
  • Do not use output for safety-critical decisions.
  • You provide and pay for your own API keys.
  • LAN MCP is off by default; use only on trusted networks.

4. Data

No account is required. Settings, logs and chats stay on device; API keys are Keystore-encrypted.
