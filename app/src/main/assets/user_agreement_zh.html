HamKit 用户协议

版本 2.0 · 生效日期：2026 年 11 月 7 日

本协议是你与 HamKit 开发者之间关于使用 HamKit 的约定。首次使用前请完整阅读；勾选同意即表示你接受本协议与《隐私政策》。

一、服务说明

HamKit 是一款业余无线电辅助工具，提供卫星过境预测、FT8/APRS 解码与台站查看、QSO 日志、SSTV 收发、双区定位、摩斯练习以及可选的 AI 助手等功能。HamKit 不是官方通联平台，不提供发射设备控制，也不能替代持照操作员的判断。

二、使用资格与合规

  • 你应在所在国家/地区取得相应业余无线电操作资格；无照不得发射。
  • 使用卫星、APRS、FT8 等功能时，必须遵守当地频率划分、功率限制、呼号标识与干扰规避规定。
  • APRS 位置公开由你自行决定并承担后果；默认关闭。
  • 不得利用 HamKit 干扰通信、冒充他人呼号、发送违法或有害内容。

三、AI 功能

  • AI 回答由第三方大模型生成，可能存在错误、过时或遗漏；请自行核实频率、过境、法规等关键信息。
  • AI 工具调用中，写入类操作（QSO 日志、过境提醒）会在执行前弹窗确认；请核对呼号、波段与时间。
  • 不要把 AI 输出用于生命、安全、医疗、法律或财务等关键决策。
  • 你需自行准备并保管 API Key，所产生的服务费用由你承担。
  • 局域网 MCP 功能默认关闭；开启后局域网内持有 Token 的设备可调用只读工具，请仅在可信网络使用。

四、账号与数据

HamKit 不要求注册账号。你的配置、日志与对话历史默认保存在本机；API Key 使用 Android Keystore 加密。卸载应用会删除本地数据，请自行备份需要保留的日志。

五、禁止行为

  • 绕过安全限制、批量自动化滥用第三方服务、攻击或扫描他人网络。
  • 反向工程、二次分发时移除版权声明或开源许可。
  • 利用本应用从事违法活动或侵犯他人权益。

六、知识产权与开源

HamKit 的代码与资源受相应开源许可保护；第三方组件（如 Miuix、OkHttp、CommonMark、高德地图 SDK）遵循其各自许可。卫星 TLE、AMSAT 状态、APRS-IS 数据来自公开数据源，版权归原提供方。

七、免责与责任限制

HamKit 按“现状”提供，不对可用性、准确性、适销性或特定用途适用性作保证。因使用或无法使用本应用造成的直接或间接损失，开发者在法律允许范围内不承担责任。

八、协议变更与终止

协议实质变更时会在应用内再次要求阅读并同意；不同意可停止使用并卸载。你也可随时在设置中撤回同意。
