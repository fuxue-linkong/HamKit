HamKit

从地面坐标到轨道预测，从摩尔斯电码到慢扫描电视。

为业余无线电爱好者打造的随身控制台——分区定位、卫星过境预测与自定义分类、CW 摩尔斯训练、SSTV / HF Fax 图像解码、FT8 与 QSO 日志、APRS 一体化。

FEATURES

核心功能

从地面坐标到轨道预测，从摩尔斯电码到数字模式 — 覆盖业余无线电日常所需。全部信号处理自研，不依赖第三方 DSP 库。

分区定位

一键获取 GPS 坐标，实时计算 CQ Zone、ITU Zone 与 6 位 Maidenhead 网格定位，配合反向地理编码显示地址（3 秒去抖、失败指数退避自动恢复）。

CQ ZoneITU ZoneMaidenheadGeocoder

卫星过境预测

自研 SGP4/SDP4 轨道计算引擎，支持 CelesTrak 与 SatNOGS 数据源，并行预测未来 48 小时过境。详情页给出实时方位 / 仰角 / 距离 / 速度与多普勒频移，内置 SatNOGS 转发器频率库与 AMSAT 状态，雷达图、星下点轨迹地图一应俱全。

SGP4CelesTrakSatNOGS多普勒雷达图AMSAT

卫星自定义分类

标签式分类，一颗卫星可归入多个分类；原「收藏」已平移为内置分类「我的关注」，历史数据自动迁移。「组织」与「提醒」彻底分离——把 50 颗卫星批量归入资料型分类，不会瞬间产生 50 条闹钟。分类配置可导出分享，导入按 id 合并。

自定义分类配置导入导出筛选

CW 摩尔斯练习

完整 Koch 课程（26 课）+ 字符组 / 呼号 / 文本训练。AudioTrack 实时合成正弦波，可调 WPM、音调与播放模式，练习进度本地跟踪，随时接着上次继续。

Koch 方法呼号训练AudioTrack进度跟踪

SSTV 慢扫描电视

纯 Kotlin 自研 DSP，零第三方依赖：正交鉴频 + VIS 头滑窗识别（±120 Hz 频偏仍可锁定），PD / Robot / Martin / Scottie / Wrasse 全族共 19 种模式。行同步 + slant 最小二乘校正补偿收发时钟差，信号瀑布图辅助调谐，实时逐行预览，VIS 缺失时可盲扫反推模式。

19 种模式VIS 识别盲扫瀑布图失谐补偿

SSTV 发射与图库

自研编码器可从相册或图库选图发射，支持呼号叠加与 VIS 头开关，无电台时可导出 WAV 用音频线接 LINE IN。解码结果自动入库：浏览、全屏查看、分享、导出相册，也能导入 WAV 录音离线重解——当时没解好的帧还有机会救回来。

编码发射呼号叠加导出 WAV录音重解

HF Fax 气象传真

接收 WEFAX 天气图：120 行/分，无 VIS、无行同步、灰度连续成像——与 SSTV 完全不同的协议，因此独立成页。适合守听海岸电台的天气图播发。

WEFAX120 行/分灰度成像

过境提醒

AlarmManager 精确闹钟 + WorkManager 每日刷新，AOS 前可配提前量提醒。重启自动恢复，支持仅白天模式；提醒开关逐星独立，与分类互不干扰。

AlarmManagerWorkManagerBootReceiver

FT8 数字模式打磨中

基于 WSJT-X / ft8_lib 标准：LDPC(174,91) 软判决解码、CRC-14、GFSK 调制与 15 秒时隙对齐，支持与真实 FT8 信号互通；内置波段选择与消息编辑，可一键生成待发消息。

FT8LDPC(174,91)GFSK软判决

APRS 位置报告

接入 APRS-IS：实时接收报文与站点列表，站点地图定位，支持消息收发与符号选择。坚守合规——不计算也不发放 Passcode，未填写时以只读模式连接（pass -1，可收不可发），首次连接前需确认持照与责任声明。

APRS-IS站点地图消息收发只读模式

QSO 通联日志

FT8 通联记录自动落库，支持增删改与呼号前缀 / 频段 / 时间范围筛选，标记完成状态。可导出 ADIF 3.1.4（.adi）与 ADX 兼容 XML（.xml），按当前筛选或全部记录导出，保存到文件或直接分享。

ADIF 3.1.4ADX XML筛选分享导出
PREVIEW

应用预览

Material 3 Expressive + Miuix KMP 双设计语言，可自定义背景图与卡片透明度，首页时间卡集成天气、UTC 与每日一言。

动态主题

MaterialKolor 从背景图自动提取色板，生成 Material 3 ColorScheme。

卡片透明度

0–100% 自由调节，scrim 遮罩保证文字对比。

Look4Sat 雷达图

极坐标雷达实时显示在境卫星方位与俯仰，视觉对齐 Look4Sat。

卫星并行预测

SGP4/SDP4 分批并行，结果按 AOS 排序，在境卫星优先。

持续定位

地址解析 3 秒去抖，失败指数退避自动恢复。

时间卡与天气

首页时间卡集成实时天气温度、UTC 与每日一言（接口失败自动回退本地文案），支持自定义背景图与遮罩色。

实时多普勒

详情页按秒刷新方位 / 仰角 / 距离 / 速度，并给出多普勒频移。

信号瀑布图

SSTV 解调信号的频率-时间图，调谐时看同步线是否稳落青色区。

APRS 站点地图

站点列表与地图双视图，符号体系完整，可查看最近站点与消息。

标准 ADIF 导出

ADIF 3.1.4 与 ADX XML 双格式，按筛选或全部记录导出，可存文件或分享。

CW 进度跟踪

Koch 课程 26 课 + 字符组 / 呼号 / 文本训练，WPM 与音调可调，进度本地保存。
