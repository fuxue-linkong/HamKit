## 二、新功能：SSTV 慢扫描电视

v3.0.0 中**完全没有这个模块**（`data/sstv/` 与 `ui/screen/sstv/` 本次全部为新增文件，
共 28 个数据层文件 + 5 个 UI 文件）。本版一次性交付接收、发射、图库三条链路。

### 1. 自研纯 Kotlin DSP（零第三方依赖）

- **正交鉴频**：8 阶 Butterworth 低通 + 多样本相位差分（`SstvDemodulator.kt`）
- **48 kHz 采集 + 增量解调**：边收边解（`SstvRecorder.kt`）
- 全部信号处理代码自持在 `data/sstv/` 内，不引入任何第三方 DSP 库

### 2. 19 种模式 + VIS 自动识别 + 盲扫兜底

- 支持 **PD-50 / 90 / 120 / 160 / 180 / 240 / 290、Robot 8 / 12 / 24 B/W、
  Robot 24 / 36 / 72、Martin 1 / 2、Scottie 1 / 2 / DX、Wraase SC2-180**，共 19 种
- 模式参数逐项核对自 slowrx `modespec.c` 与 Dayton 论文模式表；VIS 码源自
  Dave Jones (KB4YZ) 1998 年模式表
- **颜色顺序**：Martin / Scottie 是 **G→B→R**，Wraase SC2-180 是 **R→G→B** ——
  按错顺序解会让整幅图红绿蓝互换
- **Robot 24/36 行奇偶标记**：偶行分隔脉冲 1500 Hz、奇行 2300 Hz，
  不能靠行号推断（录音可能从奇数行开始）
- **VIS 头滑窗识别**，±120 Hz 频偏下仍能正确锁定；识别失败可**手动锁定模式**
- **盲扫**：VIS 头缺失时按行同步间隔反推模式，并另加**黑电平间隙结构判据**
  （Martin 1 与 Scottie 1 行周期只差 4.2%，仅靠平整度分不开）

### 3. 行同步、slant 校正与失谐补偿

- **行同步检测 + slant 最小二乘校正**：补偿收发时钟差
- **失谐补偿**：以全部行同步脉冲的平均频率估计频偏，多普勒条件下仍能还原正确亮度
- **行中同步反推**：逐行精调，降低长图累计误差

### 4. 发射链路（本版打通）

- **流式编码**：`SstvEncoder` 按行切块（单块 ≈ 95 KB），最长模式 **PD-290 全程内存 < 100 MB**
- **可选 VIS 头**、**叠加呼号**（写在右下角，便于对方确认来源）
- **两种发射方式**：手机扬声器对准电台话筒；或**导出标准 WAV** 走音频线接 LINE IN
- 编码侧与解码侧共用同一时序表，由「流式与整段编码逐样本一致」用例守护
- 发射页含**持照与频率合规提示**（未持照时建议只用「导出 WAV」本地自测）

### 5. 图库与离线重解

- 解码结果自动入库：**浏览、全屏查看、删除、分享、导出到相册**
- 缩略图用 2 的幂次降采样，不卡顿、不 OOM
- **录音重解**：保存的接收录音可重新解码 —— 当时没解好的帧还有机会救回来
- **导入音频文件**：8/16/24/32 位 PCM 与 32 位浮点、任意采样率、立体声自动下混

### 6. 接收质量

- **弱信号自适应积分窗**：SNR 10 dB 时积分窗由 5 增大到 8 样本（约 37% RMS 改善），
  SNR 30 dB 时不退步（档位保持一期值）
- **图像后处理**：直方图拉伸 + 中值降噪 + 坏行修复，可分别开关
- **信号瀑布图**：显示解调信号的频率-时间图，便于调谐与判断信号质量
- **连续接收**：收满一帧后保留模式与失谐量，自动接续下一帧（ISS 连发多张时用）
- **实时逐行预览**：图像自上而下逐步显现（可关闭）

### 7. 与卫星功能联动

- 卫星详情页新增「**接收 SSTV 图像**」入口
- **过境提醒通知直达接收态**：点通知即进入 SSTV、预置 **PD-120**（145.800 MHz，
  ARISS 的 ISS 活动频率）并自动开始接收

## 三、新功能：HF Fax 天气传真（WEFAX）

- 自研纯 Kotlin 解码器：**120 行/分（0.5 秒/行）、640 像素宽、灰度**
- **与 SSTV 完全独立的接收通路**：WEFAX 既没有 VIS，也没有行同步脉冲，
  因此单独成页而不是挂在 SSTV 里
- **白边自动对齐**
- 入口：**SSTV → 设置 → 打开 HF Fax（天气传真）**
- ⚠️ **尚未在真实 WEFAX 信号上验证过**，目前只有模块级自环测试；
  垂直方向无逐行同步（WEFAX 固有限制），可能有半行偏移

---

## 四、新功能：QSO 通联日志

- **记录 FT8 通联**，字段完整：呼号、网格、报告（发/收）、频率（MHz）、备注、完成状态
- **筛选**：呼号前缀 / 频段 / 时间范围（今天、近 7 天、近 30 天）
- 列表 / 增删改，显示「已完成 / 未完成」
- **导出 ADIF 3.1.4**（`.adi`）与 **ADX 兼容 XML**（`.xml`）
  - ADIF 字段仅允许 ASCII 32–126，非 ASCII 字符会被剥离（规范要求）
  - XML 侧支持 `COMMENT_INTL`，中文备注不丢
- **导出范围可选**：当前筛选 / 全部记录
- 导出后**保存到文件**或**直接分享**

---

## 五、新功能：卫星自定义分类

- **标签式分类**，一颗卫星可归入多个分类
- **与「收藏」合并为一套**：原「收藏」平移到内置分类「**我的关注**」，历史数据自动迁移
- **「组织」与「提醒」彻底分离**：
  - 分类归属 `Map<NORAD, Set<categoryId>>` → 组织 / 浏览 / 筛选
  - 提醒开关 `Set<NORAD>` → 是否创建过境提醒（逐星显式开关）
  - 批量把 50 颗卫星归入「线性转发器大全」这类资料型分类时，**不会**瞬间产生 50 条闹钟
- **分类配置导入 / 导出**：导出分类定义 + 卫星归属 + 卫星级提醒开关；
  导入采用**合并策略**（同 id 更新、新 id 追加、归属取并集）
- 入口：卫星页分类按钮、设置页导入导出
- 本版分类**仅名称**（颜色 / 图标 / 排序留待后续）

## 六、APRS-IS 合规整改（重要）

依据 APRS-IS 官方要求（*Authors, YOU are responsible for issuing passcodes…
Do not make this available in an ondemand fashion*）与社区反馈（HamCQ #8940 第 18/21 楼、
GitHub Issue #93）整改：

- **移除本地 Passcode 计算**：删除 `AprsPacket.passcode()` 与 `AprsConfig.computedPasscode`，
  算法不再随发行包发布
- **新增只读模式**：Passcode 留空时以 `pass -1` 连接，**可接收报文、不可注入**；
  位置上报 / 发消息 / 离线重发 / 自动 ACK 四条注入路径全部拦截
- **首次连接前持照与责任声明**：明示「你呼号下的所有流量由你本人负责」，
  未确认不得登录（持久化，确认一次即可）
- 设置页文案改为「**Passcode（需自行持有）**」，不再展示任何计算入口
- 主页与设置页显示只读横幅：「当前为只读模式：未填写 Passcode，仅接收不发送」
- 新增 `docs/APRS_IS_COMPLIANCE.md`：官方原文、整改前后对照、对外答复口径、发布前复查清单

## 七、社区反馈修复

### 1. 系统返回键全应用失效（HamCQ #8940 第 9 楼）

- 现象：虚拟导航栏机型上返回键无效，只能点左上角箭头；回到主页后仍无法返回桌面
- 修复：新增全局返回兜底，注册在 `OnBackPressedDispatcher` 上（不依赖 `navigationevent`
  回调链），优先级为 **子页出栈 → 主页面回第 0 页 → 双击返回退出**
  （首次提示「再按一次返回退出 HamKit」，2 秒内再按才退出）
- 同时收敛 `MainScreenBackHandler`、修掉搜索栏 `isBackEnabled` 硬编码

### 2. 输入法遮挡输入框（HamCQ #8940 第 9 楼）

- 现象：APRS 设置页「位置上报」输入框被键盘挡住，看不到正在输入的内容
- 修复：APRS / FT8 设置页滚动容器加 `imePadding() + imeNestedScroll()`（聚焦自动滚入可见区）；
  QSO 日志列表与编辑弹窗同样处理

## 十、升级说明

- **版本号**：4.0.0（versionCode 19）

- **下载地址**：`https://apk.hamkit.click/release/HamKit_4.0.0_19-release.apk`

  （由后台版本数据派生），服务器不可达时回退 GitHub Releases
- **兼容性**：Android 8.0（API 26）及以上
- **数据与行为变化（请留意）**：
  1. 原「收藏」自动迁移为内置分类「**我的关注**」，过境提醒行为不变；
  2. 分类是**组织**，提醒是每颗卫星的**独立开关**，两者互不影响；
  3. APRS 首次连接会弹出**持照与责任声明**，确认一次后不再重复；
     未填写 Passcode 时将**以只读方式连接**（可收不可发）；
  4. 应用图标更新，桌面图标可能在部分 ROM 上延迟刷新。
